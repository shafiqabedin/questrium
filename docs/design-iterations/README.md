# Design iterations

Dated notes from design sessions with the teacher — raw input, captured before it
is folded into `docs/BLUEPRINT.md`.

The blueprint holds the *current* design. These files hold *how it got there*,
which the blueprint cannot answer six months later.

Name files `YYYY-MM-DD-topic.md`. Capture what she actually said, including the
parts we did not act on and why. Per [ADR 0004](../decisions/0004-versioning-and-release.md).
